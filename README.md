# Automatización de Pruebas Final

Proyecto desarrollado en Java utilizando Maven, enfocado en la implementación de pruebas automatizadas, integración continua y simulación de deployment utilizando GitHub Actions.

El proyecto consiste en una calculadora simple con operaciones básicas, utilizada para aplicar conceptos de automatización de pruebas mediante JUnit y pipelines CI/CD.

## Tecnologías utilizadas

- Java 17
- Maven
- JUnit 5
- Git
- GitHub
- GitHub Actions
